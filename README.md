# 年龄队列渔业种群模拟器

一个完全离线、仅依赖 Python 3.12 标准库的按年龄队列（age-cohort）逐年种群模拟工具，
用于比较不同放流（stocking）与捕捞（fishing）方案对种群存量和产出的影响。

## 输入格式

输入为一个 UTF-8 编码的 JSON 文件（参见 `examples/sample_input.json`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `years` | 正整数 | 模拟年数 |
| `max_age` | 正整数 | 最大年龄；年龄从 0 开始，末组为“最大年龄及以上” |
| `initial_numbers` | 长度 `max_age+1` 的数组 | 各龄初始数量（非负实数） |
| `survival` | 同长度数组 | 各龄存活率，取值 0–1 |
| `fecundity` | 同长度数组 | 各龄繁殖系数（非负） |
| `weights` | 同长度数组 | 各龄个体重量（正数） |
| `capacity` | 正数 | 环境容量 |
| `scenarios` | 非空数组 | 至少一个具名方案，方案名非空且唯一 |

每个方案包含：

- `name`：唯一的方案名。
- `yearly`：按年设置的数组，每项含 `year`（1 到 `years`，方案内不重复）、
  `stocking`（非负放流数量，可省略视为 0）、`fishing`（各龄捕捞比例数组，0–1，
  省略视为全 0）。未设置的年份放流量与捕捞比例均为零。

所有方案从同一初始种群独立运行，互不继承结果，调整方案顺序不改变各自结果。

## 年内顺序

对每一个模拟年（1 到 `years`），依次执行：

1. 当年放流量加入 0 龄；
2. 按各龄捕捞比例从各龄扣除捕获数量；
3. 捕捞后剩余数量乘以该龄存活率，得到存活数量；
   自然死亡 = 捕捞后数量 − 存活数量；
4. 新生数量 = （各龄存活数量 × 繁殖系数之和）/
   （1 + 存活总量 / 环境容量）；
5. 存活个体增龄，最高龄个体留在末组（末龄汇合），新生个体进入 0 龄。

数量全程按实数计算，不取整。捕获重量按捕捞发生时的年龄重量计算。

## 运行方法

```bash
python -m fish_population --input examples/sample_input.json --output out
```

在输出目录生成：

- `population.csv`：逐年各龄数量，列名为
  `scenario,year,age,number`，保留初始第 0 年及每年末状态，
  按方案名、年份、年龄稳定排序；
- `summary.json`：每个方案的逐年放流、新生、自然死亡、各龄捕获数量、
  捕获数量合计与捕获重量，以及累计放流/新生/自然死亡/捕获数量/捕获重量，
  和末年种群数量、数量合计与重量。

## 输入校验

程序校验数组长度、有限数值、非负数量、正数重量与容量、0–1 的存活率和捕捞比例、
正整数年数、非空且唯一的方案名，以及方案内年份不重复且在模拟范围内。
非法输入会在错误信息中标明位置（如 `scenarios[0].yearly[1].fishing[2]`），
以非零状态退出，且不会生成或覆盖任何结果文件。
